**Title:** GTA 6 Clipper: free Claude Code skills (finished + live)

Here are both GTA 6 clipper skills from the video. Free. Mac and Windows. You do not have to paste a link.

**1. Open Claude Code and paste this:**

```text
Install the GTA 6 Clipper skills from this repository.
Clone the repo to a temporary folder, then copy BOTH folders inside its skills/ folder
(gta6-clipper and gta6-live-clipper) into the Claude skills folder so they sit side by side.
- Mac: ~/.claude/skills/
- Windows: %USERPROFILE%\.claude\skills\
Then run setup:
- Mac: bash ~/.claude/skills/gta6-clipper/scripts/setup.sh
- Windows: powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\.claude\skills\gta6-clipper\scripts\setup.ps1"
Tell me what it installed and whether it says READY. Then remind me to restart Claude Code.
```

**2. Restart Claude Code, then say one of these:**

- clip today's GTA 6 videos
- live clip
- clip this stream [paste a link, only if you already have one]

Your clips land in a folder called GTA6-Clips in your home folder, each with a caption and hashtags ready to post.
